# cumulo-agentes

Equipo de agentes de programación (Claude Code) para construir una suite ofimática de uso personal: lector de PDF, procesador de texto, hoja de cálculo y presentaciones, en TypeScript + React + Tauri.

| Agente | Modelo | Papel |
|---|---|---|
| `investigador` | Sonnet | Investiga en la web competencia, librerías y formatos |
| `lider` | Opus | Planifica, decide arquitectura y escribe fichas de tarea |
| `programador` | Haiku | Implementa una ficha |
| `revisor` | Sonnet | Revisa el código |
| `tester` | Sonnet | Prueba los criterios de aceptación con evidencia |

**Uso:** abre Claude Code en este repositorio y escribe `/dirigir-equipo <objetivo>`.

**Documentación:** la carpeta [`boveda/`](boveda/Inicio.md) es una bóveda de Obsidian (Abrir carpeta como bóveda). Empieza por `Inicio.md`; el diseño del equipo está en `boveda/Proyecto/Diseno del equipo.md`.
