# cumulo-agentes

Equipo de agentes de programación (Claude Code) para construir una suite ofimática de uso personal: procesador de texto, lector de PDF, presentaciones y hoja de cálculo.

- `lider` (Opus): planifica y escribe fichas de tarea.
- `programador` (Haiku): implementa una ficha.
- `revisor` (Sonnet): revisa el código.
- `tester` (Sonnet): prueba los criterios de aceptación.

Uso: abre Claude Code en este repositorio y escribe `/dirigir-equipo <objetivo>`.
